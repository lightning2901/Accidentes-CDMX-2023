# Accidentes-CDMX-2023
# Antecedentes
En un inicio este repositorio solo contenía lo siguiente: 


Análisis de accidentes en la cdmx durante el periodo de 2023, el proyecto es una libreta de jupyter usando un set de datos público.


El cual fue un set de datos que utilicé para una materia en la escuela, sin embargo recientemente he continuado utilizando este set de datos y he combinado otras tecnologías para poder explorar y visualizar estas informaciones así como tratar de ponerme a pensar qué otro tipo de hipótesis podemos hacer a partir de estas informaciones. 

# Añadidos Julio de 2025
# Arcmap
Utilizando el software de ArcMap, esos datos que en un inicio sólo me remití a explorar mediante la estadística los enriquecí con los conocimientos que adquirí en otros softwares fuera de python, en este caso ArcMap para poder visualizar dar un mayor entendimiento a la información presentada en un Data Frame.

# Hipótesis que me gustaría comprobar que son trabajo en curso
Algo que tengo en mente luego de poder salir un poco más lejos de méxico son las intersecciones y el diseño de las ciudades,algo que me motivó en un princicpio a realizar estas exploraciones era la seguridad que es una situaci+on pertinente para todos, sin embargo, recientemente me e he posido percatar de que existen ciudades con planeaciones diferentes que si bien no sons perfetctas permiten hasta cierto punto un mejor tránsito, mejor educacción vial y sobre todo para todos los usuarios, una mayor seguridad. De ahí que mi nuevo análisis y exploración se centre en comparar de manera estadística y con ayuda de GeoPandas y ArcMap la visualización y comprensión de estos fenómenos.
